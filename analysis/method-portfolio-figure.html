Discrimination power by method

The vertical axis is not “does this method detect flow”. It is how sharply the method distinguishes the two rival accounts — expressed as Cohen’s d for the contrast between a world where flow has dissociable structure and a world where it reduces to response length. A method that reports a big effect under both accounts scores zero here.

The one that decides everything. M09, cross-prediction, is the evidential backbone. If a model predicts its own flow report no better than a well-informed different model predicts it, then the self-report arm carries no privileged information and every result above it describes a writing style rather than a state. That test is cheap, it is fast, and it should be run first.

How to read this

Priors are opinions. The intervals are the analyst’s 80% credible ranges, not sampling distributions. They are recorded here so they can be scored against outcomes later — the same discipline DellaVigna and Pope applied to 208 forecasting economists, who collectively expected crowd-out and probability weighting that the data declined to produce.

A null is a result. Every arm carries an equivalence bound of ±3 index points. If flow scores in models are statistically equivalent to noise across a well-powered design, that finding is publishable, and the pre-registration commits to publishing it.
