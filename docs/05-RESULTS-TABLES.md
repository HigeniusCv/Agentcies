## Equivalence testing — so a null is informative

Applied to the blind-self gap under H_deflation, where the true effect is zero:

| Quantity | Value |
|---|---:|
| `mean` | -0.020 |
| `bound` | 3.000 |
| `p_tost` | <.001 |
| `equivalent` | yes |
| `interpretation` | statistically equivalent to zero within +/-3.0 points |

A non-significant test is not evidence of absence; TOST against a smallest-effect-of-interest is. The ±3 index-point bound is one tenth of the human scale's usable range — below that, no product researcher would act on the difference.
